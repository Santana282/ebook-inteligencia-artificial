Aprendizaje Profundo y Redes Neuronales

Objetivo de aprendizaje: Comprender la anatomía de las redes neuronales artificiales, cómo minimizan el error a través de la retropropagación y las arquitecturas especializadas para visión y secuencias.

4.1 Anatomía de una Red Neuronal

El Aprendizaje Profundo (Deep Learning) es un subconjunto del Machine Learning basado en redes neuronales artificiales con múltiples capas ocultas. Inspiradas vagamente en el cerebro biológico, estas redes procesan datos a través de nodos interconectados (neuronas artificiales).

Cada conexión entre neuronas tiene un peso (weight) y cada neurona tiene un sesgo (bias). El cálculo de una neurona es una suma ponderada de sus entradas, pasada a través de una Función de Activación (como ReLU o Sigmoide) para introducir no-linealidad, permitiendo a la red aprender patrones complejos.

4.2 ¿Cómo "aprenden"? Pérdida y Retropropagación

Una red neuronal inicializada tiene pesos aleatorios, por lo que sus predicciones son incorrectas. El aprendizaje ocurre en un ciclo iterativo:

  1. Forward Pass: Los datos pasan por la red y generan una predicción.
  2. Cálculo de Pérdida (Loss): Una función matemática mide qué tan lejos está la predicción del valor real esperado.
  3. Backpropagation (Retropropagación): Utilizando cálculo diferencial (regla de la cadena), la red calcula el gradiente de la función de pérdida con respecto a cada peso.
  4. Optimización (Descenso de Gradiente): Los pesos se ajustan ligeramente en la dirección que minimice el error (la pérdida).

Laboratorio: Definiendo una Red Neuronal en PyTorch

PyTorch es la biblioteca más popular para investigación en Deep Learning. A continuación, definimos una red neuronal simple para clasificación de imágenes usando orientación a objetos en Python.

import torch
import torch.nn as nn
import torch.nn.functional as F

class RedNeuronalSimple(nn.Module):
    def __init__(self):
        super(RedNeuronalSimple, self).__init__()
        # Capa de entrada (ej: imagen aplanada 28x28 = 784 píxeles) a 128 neuronas ocultas
        self.fc1 = nn.Linear(784, 128)
        # Capa oculta de 128 a 10 (ej: 10 dígitos posibles de salida)
        self.fc2 = nn.Linear(128, 10)

    def forward(self, x):
        # Pasar datos por la primera capa y aplicar activación ReLU
        x = F.relu(self.fc1(x))
        # Pasar por la capa de salida
        x = self.fc2(x)
        return x

# Instanciar el modelo
modelo = RedNeuronalSimple()
print(modelo)

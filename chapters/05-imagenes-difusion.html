Generación de Imágenes y Modelos de Difusión

Objetivo de aprendizaje: Comprender cómo los modelos de inteligencia artificial generan imágenes fotorrealistas a partir de descripciones de texto, utilizando procesos termodinámicos inspirados en la difusión de partículas.

5.1 El paradigma de la Difusión

A diferencia de los modelos de lenguaje que predicen la siguiente palabra, los generadores de imágenes modernos (como DALL-E 3, Midjourney o Stable Diffusion) utilizan Modelos de Difusión. El entrenamiento de estos modelos consta de dos fases opuestas:

  • Difusión hacia adelante (Forward Diffusion): Se toma una imagen real y se le añade gradualmente ruido gaussiano estático paso a paso, hasta que la imagen original es irreconocible y se convierte en puro ruido (estática de televisión).
  • Difusión inversa (Reverse Diffusion): Una red neuronal (generalmente una arquitectura U-Net) se entrena para predecir y restar ese ruido paso a paso. En la práctica, esto permite al modelo empezar con una imagen de ruido aleatorio y "esculpirla" hasta revelar una imagen coherente.

5.2 El Espacio Latente (Latent Space)

Procesar imágenes píxel por píxel requiere una cantidad colosal de memoria. Modelos como Stable Diffusion resolvieron esto operando en el Espacio Latente. En lugar de aplicar la difusión a una imagen de 1024x1024 píxeles (Pixel Space), comprimen matemáticamente la imagen a una representación más pequeña (por ejemplo, 64x64) preservando su significado semántico.

Todo el proceso de generación de ruido y eliminación (denoising) ocurre en este espacio comprimido, haciéndolo lo suficientemente ligero como para ejecutarse en tarjetas gráficas de consumo general. Al final, un "Decodificador" expande la matriz latente de vuelta a píxeles visibles.

Laboratorio: Pipeline de Difusión (Hugging Face)

El ecosistema de código abierto permite ejecutar modelos generativos localmente con muy pocas líneas de código. Aquí usamos Python y la librería diffusers.

from diffusers import StableDiffusionPipeline
import torch

# 1. Cargar el modelo pre-entrenado y moverlo a la GPU
model_id = "runwayml/stable-diffusion-v1-5"
pipe = StableDiffusionPipeline.from_pretrained(
    model_id, 
    torch_dtype=torch.float16
)
pipe = pipe.to("cuda")

# 2. Definir el prompt (condicionamiento de texto)
prompt = "Un zorro astronauta explorando Marte, arte digital detallado, 4k"

# 3. Generar la imagen (ejecuta ~50 pasos de difusión inversa)
imagen = pipe(prompt).images[0]

# 4. Guardar el resultado
imagen.save("zorro_marte.png")
